Mario成长岛

面向一年级家庭的学习与探索工作台。保留原有主角、宠物、星星和日历，增加基于知识点的数学、英语启蒙、思维探索、学习习惯与成长路线。

## 运行与检查

需要 Node.js 22 或以上；网站本身仍是可以直接静态托管的文件，不需要构建服务器。

```sh
npm ci
npm start
npm test
npx playwright install chromium
npm run test:browser
```

本地地址：`http://127.0.0.1:4173`。浏览器测试需要先启动本地服务。

## 课程与记录

- `content/`：有版本、来源及核对日期的课程包。
- `learning/engine.js`：参数化出题、学习证据、复习与预习条件。
- `learning/store.js`：IndexedDB、备用存储、备份合并与内容更新校验。
- `learning/view.js` / `learning/style.css`：新学习界面与家长设置。
- `app.js` / `app.css`：上游仅提供了打包后的 React 程序；通过少量接入改动保留原功能。新增功能不继续堆入该打包文件。

本版按家长提供的江苏凤凰出版信息设置档案；尚未核对实际版次和学校当前单元。主题顺序不等于确认某版课本的逐课目录，语文旧模块也未宣称与具体课本逐课匹配。

学习记录保存在本设备，不上传到服务器。原有 `daily-hub-*` 星星、宠物与签到记录继续使用，不作为知识掌握依据。家长设置中可以导出完整备份、合并导入。清理浏览器数据或换设备前需备份；本版尚无跨设备云同步。

## 自动读题

数学、英语听辨与思维练习默认进入每题自动播报，并保留“重播读题”“停止朗读”和“每题自动读”开关。开关保存在学习档案中，原有档案默认开启。

算式转成自然读法，选项和需要阅读的图案/路线信息一起播报，不提前读出答案或提示。英语先读中文操作说明，再播放英语题目；英语声音完整结束后才记为已听。主动请求提示、提交后的解释也会播报。

设备声音由浏览器 Web Speech API 提供，不发送题目或孩子录音到新的服务。首次自动播放被浏览器阻止时显示“重播读题”提示；切题、暂停或离开页面会取消旧播报，避免串音。缺少设备语音时明确提示，不假装播放成功。逻辑使用可注入的声音接口测试；模拟语音测试不能代替在实际设备听音。

静态资源版本为v30，HTML、模块导入地址和Service Worker缓存列表同步更新。

## 分层轻奥探索

思维探索现含间隔、移多补少、和差画图、等量代换、有条件枚举、网格路线、排除逻辑7个主题，每主题“起步/进阶/挑战”3层，可直接选层。每层有例题、分步讲解与3道不同练习，保留自动播报。原5个基础活动移入数学小课堂，历史ID与记录保留。详见[课程调整说明](docs/enrichment-course.md)。

## 发布课程更新

1. 在 `content/` 新增 `catalog-<版本>.json`，沿用 schemaVersion 1；保持已有知识点 ID 的含义稳定。当前默认包为 `catalog-2026.11.01-thinking.json`。
2. 查证来源，核对题目与解释；更新 `version`、`checkedAt` 与审查说明。规则校验不能替代教师审题。
3. 运行 `npm run content:build -- catalog-<版本>.json` 生成 SHA-256 清单，再运行测试。
4. 随网站发布内容包与 `content/manifest.json`。如更改首次离线安装的基础课程包，也需更新 `sw.js` 的 CORE 列表及缓存版本。

应用启动及手动检查时读取清单，验证哈希、结构、来源关联与前置知识依赖后启用新版；失败或离线时继续使用已有包。当前练习及历史作答保留当时的题目、答案、提示与版本快照。

动态选题来自作答与复习记录，题目来自受约束的参数生成器。系统不会直接把网上搜索结果或未经核验的模型回答推送给孩子；持续检索与内容发布由后续审核流程承接。

完整设计、现状限制和下一阶段见 [系统设计说明](docs/learning-redesign.md)。
