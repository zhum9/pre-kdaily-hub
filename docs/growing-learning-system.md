# 随孩子成长的精简学习系统

2026-11-01。家庭起点是2026年9月进入一年级，英语尚未开课，数学与语文出版信息为江苏凤凰教育出版社。起点不等于系统的永久年级。

## 年级、课程和能力分开

家长设置支持自动推算与手动指定一至六年级。自动模式默认一年级入学年份2026；北京时间2027年6月30日仍为一年级下学期，7月1日至8月31日推荐二年级暑期预习，9月进入二年级上学期。2月切换下学期属于可被手动设置覆盖的产品规则，不能替代各地每年的实际开学日期。入学前年份显示入学准备，超过小学阶段保留六年级复习，不生成不存在的七年级小学课程。

年级决定推荐范围，不写入任何掌握证据。数学优先当前年级课堂目标，保留到期薄弱点复习；下一学期和相邻年级拓展由家长开启，带前置条件的主题检查已有证据。思维推荐相应层次，仍允许孩子按兴趣选择起步、进阶或挑战。英语实际起点独立分为零基础、生活短句、多步指令与表达，不随年级强行跳级。语文阅读建议按年级调整，旧拼音、生字、古诗仅作按需复习资源。

首批数学保留原一年级主题，新增二至六年级各4个精选主题，涉及等量组、平均分、余数含义、周长面积、平均数、小数、分数、按比分配、百分数和圆面积。它不是各年级全册课程，也没有冒充某版教材的单元顺序。三年级起增加最坏情况保证、分类数正方形、轮流游戏策略3个推理主题，每个3层。后续应继续逐题核对和增加表示方式、应用情境，不以把数字变大代替难度进阶。

老档案字段缺失时补默认值；以前已选一年级下学期的档案保留为手动模式，避免覆盖家长原来明确设置的学期。新练习保存年级/学期/英语起点快照；切换年级不自动续入上一年级未完成题目，历史课次和证据保留。旧备份仍可导入，新备份包含年级设置和科学观察。

## 科普从短文章改成探究课程

原7篇按日期固定轮换的科普被12主题、36节探索、72道有解释的思考题替代：光影、声音、空气、水的变化、沉浮、磁铁、种子、食物网、地月、天气、纸桥和过滤。每个主题包含三个不同目标：理解现象、证据推理、设计探究。高层要求读表、比较可比性、排除替代解释、说明模型和结论边界，而不是记更多名词。

流程为预测→概念与易错点→两道证据/推理挑战→动手步骤→真实观察。预测可以选择不确定，不作对错评分。示例表格均标“练习用示例记录，不是孩子实测”，不捏造观测。实测可记未动手、观察到、结果不同或未看清；未做实验也能保存思考进度，但不显示为已有动手记录。保存新观察不覆盖旧观察事件。

每节保留当时的题目、答案、资料来源、活动和内容版本快照。作答和预测即时保存，刷新可从主题页继续；观察文本通过明确的保存按钮保存。默认自动播报题目、表格每行与选项；讲解和操作步骤可单独播放，离开页面取消声音。读题不提前播报正确选项与解析。设备语音仍受浏览器自动播放与所装声音限制。

科学细节依据NASA、USGS、NOAA、Smithsonian、ACS、大学推广部、Science World和Science Buddies的原始教育资料核对，逐主题保留链接和核对日期。活动是原创家庭演示：不把凝结说成漏水，不把日常月相说成月食，不把所有金属说成可被吸住，不把萌发与长期植物生长混淆，不把纸滤当饮水净化。安全说明随材料和活动出现，不使用高处投放、热水、激光或可吞咽磁铁。

## 精简入口和持续更新

移除食谱、前庭、专注力和与思维重复的旧小游戏页面与菜单；旧签到、星星和宠物不删除。拼音、生字、古诗收进同一语文阅读入口。核心围绕数学、思维、英语，科普与阅读作为可选拓展；成长路线和设置承担查看记录与家长调整。

主内容包 `catalog-2026.11.01-growth.json` 与独立科学包 `science-2026.11.01.json` 都由清单和SHA-256校验。主课程作者源在 `scripts/progression-content.mjs`，科学课程作者源在 `scripts/science-content.mjs`，分别运行 `npm run content:build`、`npm run content:science` 生成可发布JSON。修改知识含义须使用新ID；每次发布更新版本，保持历史包和快照可解释。

打开模块和手动检查时自动取本站已发布内容；离线或校验失败时使用最后有效版本。联网搜索提供编辑参考，核对与发布后再成为孩子的课程，不把未经核对的网页或模型输出直接插入题库。尚无云账号、多设备自动同步、自动抓取发布流程。继续使用IndexedDB、可合并备份及PWA，避免为了未来需求引入无配置的数据库和庞大后台。

## 验证

验证自动与手动年级边界、年级实际改变出题路线、英语起点独立、旧备份兼容；对新数学和思维生成器使用独立计算或穷举求解，检查选项唯一且答案正确。科学检查来源引用、层级、示例数据标注、快照不变、语音证据完整、实际观察备份和离线使用。旧的学习、语音和轻奥测试继续回归。模拟语音不能代替家长在孩子常用设备上实际听音。
