# 一年级轻奥探索：本轮课程调整

原五类活动偏入门，后续有排序、搭配，但没有逐步发展为轻奥课程。本轮同时调整生成器、分层入口、推荐与记录。

旧知识点ID `t-pattern`、`t-rank`、`t-enumerate`、`t-paths`、`t-balance` 移入数学小课堂的“数学思维基础”。原ID、证据和题目快照保留；不参与课堂日常目标的默认选题，不混入教材进度设置。未完成的旧思维基础练习归档保留，避免升级后继续把它当作轻奥第一课。

新课程7主题，每主题3层，共21个独立知识点，均为可选拓展。用画图、摆物、枚举和假设理解，不冒称教材必修目录或机构原版课程。

| 主题 | 起步 | 进阶 | 挑战 |
| --- | --- | --- | --- |
| 间隔与排队 | 物体与间隔 | 端点变化与围成圈 | 分段、共享连接点去重 |
| 移多补少 | 移一份让差缩小两份 | 保留指定差、倒推原差 | 三盒均分的最少移动 |
| 和差画图 | 两份的和与差 | 移动或各用掉后的倒推 | 三份统一基准 |
| 等量代换 | 连续替换 | 对照两组，消去共同部分 | 合并后按整体分组 |
| 有条件枚举 | 固定一种有序列举 | 数量上限 | 同时满足总值和总枚数 |
| 网格路线 | 按第一步分组 | 必经指定交点 | 避开障碍，全部与排除的比较 |
| 排除与逻辑 | 三角色排除 | 四角色、多条件对应 | 逐一假设、统计符合实际的句数 |

例如“两人共有14颗，小兔给小熊2颗后相等，小兔原来几颗”：需要先理解移动让差缩小4颗，再用图把原总数分成相同部分与多出部分，得到9颗。

每层先有例题、分步思路与语音，再生成3道不同练习。例题不计入证据、不作为本轮评分题复用。可以直接选进阶或挑战；选择高层不会生成掌握标记。推荐记住最近选择，达到掌握证据后可推荐同主题下一层；各层分别保存证据，不用基础层分数代表挑战层已会。

提供和差条形示意图及带必经点、障碍点的网格。图示不提前给出结果。继续支持自动读题、选项、主动请求的提示、提交后的解释。保留兴趣和方法表达观察，不依据速度、少量答对或层级评定天赋。

现有跨天、不同题目的独立证据规则仍适用，包含迁移与自主解释，不把一轮全对称为“掌握”。一轮独立全对且有解释记录时，提供自愿尝试下一层的入口。

题目为本项目原创。分层方式参考[NRICH低起点、多层拓展任务](https://nrich.maths.org/low-threshold-high-ceiling-resources-primary-teachers)，推理与表达参考[教育部数学课程标准](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf)。核对日期2026-11-01，不冒称教师逐题审定。

验证包括有限变式覆盖、例题去重，以及独立枚举求解器：逐项枚举移动量、数量分配、代币组合、角色排列、真假条件与网格方向序列，检查答案唯一且条件充分。内容版本2026.11.01.2，静态资源和离线缓存v30。
